# MCP-2 — MCP-сервер «Город пользователя»

**MCP-2** — автономный сервер Model Context Protocol на **Kotlin + Spring Boot 3 (WebFlux)** поверх
официального Java SDK для MCP. Работает по транспорту **Streamable HTTP**, поэтому может быть развёрнут
в Docker и доступен как обычный HTTP-хост в интернете (не stdio).

Это параллельный (второй) MCP-сервер рядом с `mcp/` («папкин помощник»), но с **одним-единственным**
инструментом: определение города пользователя по его исходящему IP-адресу.

## Инструмент

| Инструмент | Описание | Источник |
|---|---|---|
| `get_user_city` | Город пользователя по IP: возвращает `city`, `country`, `region`, `lat`, `lon` и `ip` | `ip-api.com` (бесплатно, без ключа) |

Инструмент **fail-open**: если внешний API недоступен, вернул ошибку или запрос превысил таймаут (5 с),
вместо исключения возвращается карта `{error: "Не удалось определить город по IP", message: <детали>}`.
Он никогда не «подвешивает» запрос.

## Требования

- JDK 21
- Gradle 8.14.3 (wrapper в каталоге модуля)
- Docker (для контейнерного запуска)
- Исходящий доступ в интернет (инструмент ходит во внешний API)

## Локальный запуск

```bash
cd mcp2
gradlew.bat bootRun            # Windows
./gradlew bootRun              # Linux/macOS
```

По умолчанию сервер слушает `http://localhost:8080`; Streamable HTTP endpoint —
`http://localhost:8080/mcp`. Порт можно переопределить переменной окружения `SERVER_PORT`:

```powershell
$env:SERVER_PORT="8790"; gradlew.bat bootRun
```

## Docker

```bash
docker build -t mcp2-server:0.1.0 .
docker run -d -p 8790:8080 --name mcp2-server mcp2-server:0.1.0
```

или через compose:

```bash
docker compose up -d --build
```

## Публичный доступ в интернет

Контейнер пробрасывает порт: хост `8790` → контейнер `8080`. Чтобы MCP-клиент (Claude, opencode и др.)
подключился, `http://<публичный-хост>:8790/mcp` должен быть доступен извне:

1. Откройте порт `8790` в файрволе хостинга/облака, настройте security group.
2. (Опционально) поднимите reverse-proxy (nginx/Caddy) и выдайте TLS по `https://<домен>/mcp`.
3. В настройках MCP-клиента укажите URL: `http://<публичный-хост>:8790/mcp` или `https://<домен>/mcp`.
4. Убедитесь, что у контейнера есть исходящий доступ в интернет — иначе инструмент вернёт ошибку.

## Пример вызова инструмента

```bash
curl -X POST http://localhost:8790/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"tools/call","params":{"name":"get_user_city","arguments":{}},"id":1}'
```

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SERVER_PORT` | `8080` | Порт сервера |
| `SPRING_AI_MCP_SERVER_NAME` | `MCP-2` | Имя сервера (видно клиентам) |
| `SPRING_AI_MCP_SERVER_VERSION` | `0.1.0` | Версия сервера |

Публичные ключи/токены не требуются — ip-api.com бесплатен и открыт.

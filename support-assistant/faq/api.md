# API и интеграции

## Лимиты API

По тарифам: Free — 100 запросов/сутки, Pro — 10 000, Team — 50 000. При превышении API возвращает HTTP 429 с заголовком `Retry-After`. Сброс лимитов — в 00:00 UTC.

## Как получить API-ключ

Профиль → «Разработчику» → «Создать ключ». Ключ показывается один раз — сохраните его сразу. Отозванный ключ перестаёт работать в течение минуты.

## Ошибка 401 при запросах к API

Проверьте: ключ передаётся в заголовке `Authorization: Bearer <ключ>`; ключ не отозван; аккаунт не заблокирован (заблокированный аккаунт не проходит авторизацию API — ошибка 401/403).

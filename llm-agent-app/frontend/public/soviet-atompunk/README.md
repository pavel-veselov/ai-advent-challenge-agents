# Soviet atompunk skin — примечания к ассетам

Скин «пультовой станции» реализован **только средствами CSS** в `src/index.css`
(классы компонентов не менялись — это гарантия того, что логика и раскладка не тронуты).

Внешние ассеты (картинки, шрифты, иконки) **не используются**:

- звезда, орбита атома, клёпки, чертёжная сетка, сканлайны, виньетка —
  инлайн CSS-градиенты и SVG `data:`-URI, нарисованные с нуля;
- шрифты — системные стеки (`Arial Narrow` / `PT Sans Narrow` для трафаретных
  заголовков, `Consolas` / `Courier New` для приборных шкал);
- добавлено 0 КБ бинарных ассетов, никаких лицензионных рисков.

Единственный файл-ассет проекта — `public/favicon.svg` (красная звезда на
эмали), перерисован вручную в той же палитре.
